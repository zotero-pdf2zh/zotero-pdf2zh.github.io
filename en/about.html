About ​

Zotero PDF2zh is a plugin for translating PDFs using PDF2zh and PDF2zh_next in Zotero.

Project Introduction ​

This plugin perfectly preserves original formatting, supports multiple translation engines and services, allowing you to easily translate PDF literature in Zotero.

Core Features ​

  • 🚀 Dual engine support (PDF2zh and PDF2zh_next)
  • 📄 Perfectly preserve original formatting, formulas, and layout
  • 🔄 Multiple translation modes (translate, crop, compare, etc.)
  • 🌐 Support multiple translation services (OpenAI, DeepSeek, Zhipu, etc.)
  • ⚙️ Flexible configuration options
  • 🆓 Built-in free translation service
  • 📦 Automatic update functionality
  • 🐳 Docker deployment support
