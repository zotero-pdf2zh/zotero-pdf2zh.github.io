Configuration

  • 🧠 DeepSeek V4

    Supports deepseek-v4-flash / deepseek-v4-pro with explicit Thinking controls; PDF translation defaults to Thinking disabled.

  • 🔄 Safe Environment Updates

    Keeps existing uv/conda environments and installs Python translation dependencies in place.

  • 📄 PDF State Management

    Correct LR/TB, Crop, Compare and Crop-Compare transitions, with terminal-result guards against repeated processing.

  • 🌐 Multiple Services

    Supports OpenAI-compatible providers, DeepSeek, Zhipu, Aliyun and more, including model-list fetching for supported providers.

  • 🔐 Safer Defaults

    Server binds to localhost by default, upload filenames are validated, and API keys/tokens are masked in logs.

  • ⚙️ Configuration Migration

    Existing user values and custom fields are preserved instead of being overwritten from example files on every startup.

  • 📦 Release-built Artifacts

    The XPI and server.zip are built from the tagged source during release, avoiding stale static packages.

  • 🎯 Zotero Integration

    Integrated into Zotero context menus with batch processing and Chinese/English UI support.

v4.1.1 hotfix

Windows Conda users: this release installs into the canonical environment and asks conda for the real Python path. It no longer creates staging or backup environments.

After upgrading the Server, the first launch still asks whether to refresh the translation environment. Choosing Y is recommended.
