🎯 按使用阶段查找 ​

不确定自己处于什么阶段？请根据当前情况选择：

阶段 1：准备安装 ​

正在做什么：准备开始安装插件

常见问题：

  • 需要什么前置条件？
    • Python 3.12.0 - 下载
    • Zotero 8 - 下载
  • Windows 用户需要管理员权限吗？
    • 是，请使用管理员身份运行 cmd.exe

继续：安装指南

阶段 2：安装中 ​

正在做什么：正在安装 Python 虚拟环境或下载文件

常见问题：

  • uv/conda 安装后命令不识别 → 虚拟环境问题
  • server.zip 下载失败 → 网络问题
  • Python 版本不兼容 → 环境配置问题

阶段 3：启动服务 ​

正在做什么：运行 python server.py 或 Docker 容器

常见问题：

  • 服务启动失败 → 环境配置问题
  • 端口被占用 (8890) → 网络问题
  • DLL 初始化失败 → 环境配置问题

阶段 4：安装插件 ​

正在做什么：在 Zotero 中安装 xpi 插件

常见问题：

  • 插件安装后无反应 → 重启 Zotero
  • 插件版本不兼容 → 确保使用最新插件 v4.1.x，以及受支持的 Zotero 版本（7 / 8 / 9 / 10）

阶段 5：配置翻译 ​

正在做什么：配置 API Key 和翻译服务

常见问题：

  • 没配置 API 可以用吗？ → 翻译服务问题
  • 如何选择翻译服务？ → 翻译服务问题
  • API Key 配置后仍报错 → 翻译服务问题

阶段 6：开始翻译 ​

正在做什么：第一次尝试翻译 PDF

常见问题：

  • 翻译卡住不动 → 网络问题
  • 扫描版 PDF 翻译失败 → 插件功能问题
  • 翻译质量不满意 → 翻译服务问题

阶段 7：遇到错误 ​

正在做什么：使用过程中出现错误提示

快速排查步骤：

  1. 查看终端错误

    • 终端中的错误信息通常包含关键线索
    • 复制完整错误信息到文本文件

  2. 搜索文档

    • 使用 Ctrl+F / Cmd+F 在本文档中搜索错误关键词
    • 查看 问题索引 中的相关分类

  3. 尝试以下方案

    • 切换端口：python server.py --port=9999
    • 重启服务：停止并重新运行 python server.py
    • 检查配置：确认 API Key 和 URL 正确

  4. 仍未解决

    • 阅读 有效提问指南
    • 在 GitHub Issues 提问
    • 加入 QQ 群：5群 1064435415（入群口令请到 GitHub / Gitee 仓库主页查看）
