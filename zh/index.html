v4.1.1 升级说明
配置说明

  • 🧠 DeepSeek V4

    支持 deepseek-v4-flash / deepseek-v4-pro，可显式关闭或开启 Thinking；PDF 翻译默认关闭 Thinking。

  • 🔄 安全环境更新

    自动沿用已有 uv/conda，并在当前环境中直接安装/更新 Python 翻译依赖。

  • 📄 PDF 状态管理

    正确处理 LR/TB、Crop、Compare、Crop-Compare，阻止终态 PDF 被重复加工。

  • 🌐 多服务支持

    支持 OpenAI 兼容格式、DeepSeek、智谱、阿里云等多种翻译服务，并可获取部分服务的模型列表。

  • 🔐 更安全的默认值

    Server 默认只监听 localhost，上传路径校验加强，API Key / token 日志自动脱敏。

  • ⚙️ 配置迁移

    更新后保留用户配置和自定义字段，不再每次启动用 example 文件覆盖用户设置。

  • 📦 Release 安装包

    插件 XPI 与 server.zip 由 Release 流程根据当前 tag 构建，避免静态安装包和源码不同步。

  • 🎯 Zotero 集成

    集成到 Zotero 右键菜单，支持批量翻译和中英文界面。

v4.1.1 hotfix

Windows Conda 用户：当前版本在正式环境里直接安装依赖，并用 conda run 确认 Python 路径，不再创建 staging / backup 环境。

已有用户升级 Server 后首次启动仍会询问是否更新翻译环境。建议选择 Y。

详见 翻译环境安装与更新。
